> Adapted from *A Hacker's Guide to NCURSES*, by Eric S. Raymond.

This guide is a hacker's tour of the ncurses library and utilities. It discusses design philosophy, implementation methods, and the conventions used for coding and documentation. It's recommended reading for anyone who is interested in porting, extending or improving the package.

The guide dates from the 1990s. This edition corrects the file names, function names and addresses that have changed since, and the [errata](/ncurses/appendix/) list each correction with what it was checked against.
