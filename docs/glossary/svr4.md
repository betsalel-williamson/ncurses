# SVr4

**SVr4** is System V Release 4, the AT&T Unix release whose curses library ncurses was written to replace. SVr4 curses, together with its [terminfo](terminfo.md) database and its panel, menu and form libraries, is the model that [X/Open Curses](x-open-curses.md) standardized. ncurses copies its behavior where the standard leaves details open.

Compare [BSD curses](bsd-curses.md).
