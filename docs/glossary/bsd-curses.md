# BSD curses

**BSD curses** is the original curses library, written by Ken Arnold at Berkeley for BSD Unix around 1980 and built on [termcap](termcap.md). System V reworked it on top of [terminfo](terminfo.md), and that line led to [SVr4](svr4.md) curses and [X/Open Curses](x-open-curses.md). The 4.4BSD version is the other library ncurses replaces.

See [`ncurses`](../../man/ncurses.3x).
