# X/Open Curses

**X/Open Curses** is the standard for the curses interface, published by The Open Group. ncurses implements Issue 7 of it. Issue 4 Version 2 added the wide-character functions, and the standard is also called XSI Curses, from the X/Open System Interfaces it belongs to. Where the standard leaves behavior open, ncurses follows [SVr4](svr4.md) curses, and the functions it adds are marked as extensions in the man pages.

The PORTABILITY section of each man page says how ncurses relates to the standard. See [`ncurses`](../../man/ncurses.3x).
