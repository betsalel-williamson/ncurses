# Mouse

Now that you have seen how to get keys, let's do the same thing with the mouse. Usually each UI allows the user to interact with both the keyboard and the mouse. These pages explain how a program asks for mouse events, reads them, and uses them to pick from a menu. They merge chapters of two guides, so each fact appears once:

- *Writing Programs with NCURSES*, by Eric S. Raymond and Zeyd M. Ben-Halim
- *NCURSES Programming HOWTO*, by Pradeep Padala
