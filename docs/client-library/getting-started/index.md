# Getting started

These pages introduce programming with `curses`: what it is, where it came from, and how to write, compile and run a first program. They merge the opening chapters of two guides, so each fact appears once:

- *Writing Programs with NCURSES*, by Eric S. Raymond and Zeyd M. Ben-Halim
- *NCURSES Programming HOWTO*, by Pradeep Padala
