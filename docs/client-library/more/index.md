# Other libraries, tools and programs to try

Besides the curses library itself, ncurses comes with three libraries that add more: [panels](../panels/index.md), [menus](../menus/index.md) and [forms](../forms/index.md). These pages go further. They describe widget libraries and tools built on curses, then give six small programs written for fun, each of which runs in this page. The pages come from the Other Libraries, Tools and Widget Libraries, and Just For Fun chapters of the *NCURSES Programming HOWTO*, by Pradeep Padala.

## Guide

- [Widget libraries and tools](widget-libraries.md)
- [The Game of Life](life.md)
- [Magic square](magic-square.md)
- [Towers of Hanoi](hanoi.md)
- [Queens puzzle](queens.md)

The programs don't show the best way to use ncurses. They're here to give beginners ideas, and they leave plenty of room for improvement.
