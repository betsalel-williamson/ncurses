# Keyboard

No GUI is complete without a strong user interface, and to interact with the user, a curses program should be sensitive to key presses and mouse actions. These pages deal with the keys: how `getch()` reports them, and how a program uses arrow keys to move through a menu. They come from the *NCURSES Programming HOWTO*, by Pradeep Padala.
