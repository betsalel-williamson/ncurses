# Screen manipulation and other features

These pages cover functions that help a program manage the screen efficiently, which matters most in games, and a few miscellaneous features: cursor visibility and leaving curses mode for a while. The line-drawing characters are under [Output](../output/line-drawing-characters.md), next to the forms-drawing characters. They come from the *NCURSES Programming HOWTO*, by Pradeep Padala. Cleaning up with `endwin()` before a program exits is covered in [Hello World](../getting-started/hello-world.md#endwin).
