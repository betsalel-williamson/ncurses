# Menus library

The `menu` library builds menus: screen displays that let a user choose one or more items from a set. These shards merge the menu chapters of two guides, so each fact appears once:

- *Writing Programs with NCURSES*, by Eric S. Raymond and Zeyd M. Ben-Halim
- *NCURSES Programming HOWTO*, by Pradeep Padala
