# Output

Once `curses` is initialized, you put characters and strings on a window and then refresh it so the terminal matches. These pages cover the three classes of output functions and the forms-drawing characters. They merge chapters of two guides, so each fact appears once:

- *Writing Programs with NCURSES*, by Eric S. Raymond and Zeyd M. Ben-Halim
- *NCURSES Programming HOWTO*, by Pradeep Padala
