# Input

Printing without taking input is boring. These pages cover the functions that read from the keyboard: single characters, whole strings and formatted input. They merge chapters of two guides, so each fact appears once:

- *Writing Programs with NCURSES*, by Eric S. Raymond and Zeyd M. Ben-Halim
- *NCURSES Programming HOWTO*, by Pradeep Padala
