# Forms library

The `form` library builds on-screen forms for data entry and program control. These shards merge the forms chapters of two guides, so each fact appears once:

- *Writing Programs with NCURSES*, by Eric S. Raymond and Zeyd M. Ben-Halim
- *NCURSES Programming HOWTO*, by Pradeep Padala
