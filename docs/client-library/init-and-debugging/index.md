# Initialization, wrapup and debugging

These pages describe the functions that start and end a curses program, send its output to the terminal, read a terminal's description without starting curses, and trace what the library does. They supplement the manual pages, which have the full details. They come from the Function Descriptions section of *Writing Programs with NCURSES*, by Eric S. Raymond and Zeyd M. Ben-Halim.
