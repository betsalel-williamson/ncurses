# Windows and screen updates

A `curses` window is an imaginary screen: you draw on it, then ask `curses` to make the terminal match. These pages explain windows, how the screen gets updated, and how to create, border and move windows. They merge chapters of two guides, so each fact appears once:

- *Writing Programs with NCURSES*, by Eric S. Raymond and Zeyd M. Ben-Halim
- *NCURSES Programming HOWTO*, by Pradeep Padala
