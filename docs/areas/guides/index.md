# Guides

Guides to one part of ncurses at a time: the libraries built on curses, building and installing ncurses, and how its source is organized. Each stands on its own, and assumes you know the basics from [Learn curses](../tutorials/index.md).

## Libraries

- [Panels library](../../client-library/panels/index.md): overlapping windows stacked in depth.
- [Menus library](../../client-library/menus/index.md): menus of items a user can choose from.
- [Forms library](../../client-library/forms/index.md): forms of fields a user can fill in.
- [Other libraries, tools and programs to try](../../client-library/more/index.md): widget libraries, and small games written with curses.

## Building and contributing

- [Installing ncurses](../../contributor/install/index.md): building ncurses from source, its configure options, and compatibility with older releases.
- [A hacker's guide to ncurses](../../contributor/hackguide/index.md): how the source is organized, for anyone who wants to change it.
- [The Ada95 binding](../../contributor/ada/index.md): using ncurses from Ada.
