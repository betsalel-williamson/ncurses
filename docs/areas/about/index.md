# About this edition

This edition is a tribute to the people who wrote ncurses and its documentation; the [credits](https://betsalel-williamson.github.io/ncurses/credits/) name them. These pages say what is in the current release and how this edition changed the text it is built from.

- [Release announcement](../../contributor/announce/index.md): what is new in this release of ncurses.
- [Appendix](../../appendix/index.md): every change this edition makes to the original text, how those changes were checked, and what the migration taught.
