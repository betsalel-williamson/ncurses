# Reference

The ncurses manual pages, for looking up one function, program or file format, and the glossary of terms the guides and pages use.

## Manual pages

- **Library functions (3X):** every function in the curses, panel, menu and form libraries, grouped by page as `man` groups them.
- **Programs (1, 1M):** the programs that come with ncurses, such as `tic`, `infocmp`, `tput` and `clear`.
- **File formats and conventions (5, 7):** the terminfo format and the conventions the library follows.

Each manual page has the same sections: NAME, SYNOPSIS, DESCRIPTION, RETURN VALUE, PORTABILITY and SEE ALSO, with others where a page needs them.
