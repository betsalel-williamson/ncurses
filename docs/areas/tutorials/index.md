# Learn curses

Tutorials that teach curses programming in C, from a first program to the finer points. Read them in order if you are new to curses: each one builds on the ones before it.

## Tutorials

- [Getting started](../../client-library/getting-started/index.md): what curses is, where it came from, how to get it, and a first program.
- [Windows and screen updates](../../client-library/windows/index.md): windows, the screen, and how a refresh updates the terminal.
- [Output](../../client-library/output/index.md): putting characters and strings on a window, and drawing lines and boxes.
- [Attributes and colors](../../client-library/attributes/index.md): bold, underline, reverse video and color.
- [Input](../../client-library/input/index.md): reading characters and strings from the keyboard.
- [Keyboard](../../client-library/keyboard/index.md): function keys, arrow keys and other special keys.
- [Mouse](../../client-library/mouse/index.md): mouse events and a menu you can click.
- [Screen manipulation and other features](../../client-library/screen/index.md): coordinates, saving the screen, the cursor, and leaving curses mode.
- [Initialization, wrapup and debugging](../../client-library/init-and-debugging/index.md): starting and ending a curses session, and tracing a program.
- [Hints, tips and compatibility](../../client-library/hints/index.md): cautions, resizing, several terminals, and older curses.
