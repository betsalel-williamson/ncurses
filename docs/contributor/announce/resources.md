## Other resources

The distribution provides a newer version of the terminfo-format terminal description file once maintained by [Eric Raymond](http://www.catb.org/~esr/terminfo/) . Unlike the older version, the termcap and terminfo data are provided in the same file, which also provides several user-definable extensions beyond the X/Open Curses specification.

You can find lots of information on terminal-related topics not covered in the terminfo file in [Richard Shuford's archive](https://shuford.invisible-island.net/) ([original](http://web.archive.org/web/*/http://www.cs.utk.edu/~shuford/terminal)). The collection of computer manuals at [bitsavers.org](http://www.bitsavers.org/pdf/) has also been useful.
