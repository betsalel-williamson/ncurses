# Development activities

Zeyd Ben-Halim started ncurses from a previous package pcurses, written by Pavel Curtis. Eric S. Raymond continued development. Jürgen Pfeifer wrote most of the form and menu libraries.

Ongoing development work is done by [Thomas E. Dickey](mailto:dickey@invisible-island.net). Thomas E. Dickey has acted as the maintainer for the Free Software Foundation, which held a [copyright on ncurses](https://invisible-island.net/ncurses/ncurses-license.html) for releases 4.2 through 6.1. Following the release of ncurses 6.1, effective as of release 6.2, copyright for ncurses reverted to Thomas E. Dickey (see the [ncurses FAQ](https://invisible-island.net/ncurses/ncurses.faq.html#relicensed) for additional information).

Contact the current maintainers at

> <bug-ncurses@gnu.org>

This list is open to anyone interested in helping with the development and testing of this package.
