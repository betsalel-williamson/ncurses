# Modern xterm versions

The terminfo database included with this distribution assumes you are running a modern xterm, so its `xterm` entry uses `xterm-new`. The older X11R6 entry (`xterm-r6`) and X11R5 entry (`xterm-r5`) are provided as well. See the [`--without-xterm-new`](configure-options/without.md#--without-xterm-new) configure option if you are unable to update your system.
