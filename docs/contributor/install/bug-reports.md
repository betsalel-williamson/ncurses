# Bug reports

Send any feedback to the ncurses mailing list at bug-ncurses@gnu.org. It's a GNU Mailman list, and you can join it from its [subscription page](https://lists.gnu.org/mailman/listinfo/bug-ncurses).

The hacker's guide has some guidelines on [how to report bugs](../hackguide/reporting-bugs.md) in ways that will get them fixed most quickly.
